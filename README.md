# 🔐 Advanced Password Strength Analyzer

An advanced cybersecurity project that evaluates password strength using:
- Entropy calculation
- Pattern and repetition detection
- RockYou leaked password dataset
- Brute-force attack time estimation

## 🚀 Features
- Entropy-based scoring (0–100)
- Detects common, repeated, and sequential passwords
- Leetspeak normalization
- Real-world attack simulation

## 🛠 Tech Stack
- Python 3
- Regular Expressions
- Cybersecurity principles (OWASP, NIST)

## ▶ How to Run
1. Clone the repository
2. Place `rockyou.txt` in the project folder
3. Run:
   ```bash
   python password_strength_analyzer.py
